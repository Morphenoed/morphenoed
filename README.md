## Mykhailo Zelia

MSc Computer Science student at the University of Stuttgart, ranked 1st in my cohort.
I work on algorithms for route planning and geographic data, performance-critical C++ and distributed systems.

### Public projects

- **[growing-rectangles](https://github.com/Morphenoed/growing-rectangles)** (Java): collision-free map label placement for all 12.5 million OpenStreetMap labels worldwide in about 23 minutes. Implementation of my bachelor thesis, [published on OPUS](https://doi.org/10.18419/opus-17772).
- **[distributed-stock-exchange](https://github.com/Morphenoed/distributed-stock-exchange)** (Python, team of 3): fault-tolerant exchange with a replicated order book, leader election, reliable FIFO multicast and failover.
